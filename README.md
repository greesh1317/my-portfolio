# My Portfolio

My personal portfolio built with React and Framer Motion.

## Live Demo

🌐 https://my-portfolio-w7dq.vercel.app/

## Features

- Responsive Design
- Smooth Framer Motion Animations
- Modern UI
- Mobile Friendly
- Interactive Hero Section

## Tech Stack

- React
- Framer Motion
- CSS3
- JavaScript
- Git
- Vercel
